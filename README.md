# Carte Publicom

Cartographie interactive des supports Publicom à Libreville.

## Application

L’application Next.js se trouve dans `publicom-carte-v2/web`.

```bash
cd publicom-carte-v2/web
npm install
npm run dev
```

Les médias diffusés par l’application sont versionnés dans `publicom-carte-v2/web/public/media`. Les archives photo haute définition locales et les dépendances ne sont volontairement pas incluses dans Git.
